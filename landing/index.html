Pascaal

Resolve agent → human. Attribute every action.

Imprints bind AI agents to a responsible human. Grants authorize exact actions with budgets. Barricade enforces, Freeroam observes, Trackline shows users what their agents did. Built on the open Hallmark protocol.

The problem

Agents hold emails, burn API spend, write to workspaces — and platforms can't answer: which paying user is responsible? Blocking them loses usage. Accepting them blind loses attribution and creates liability.

Imprint

Every agent wears a provable imprint tracing to a single human via verifiable lineage.

Grants

Computed authorizations: lineage + capability + budget + action + lifetime + jti. ~116µs to verify.

Barricade

Plugin enforcing imprint + grant per surface. Enroll at first responsibility, not first contact.

Freeroam

Zero-friction observation; cooperating agents self-identify. The wedge to Barricade.

Trackline

User receipts: what the agent did, cost, grant ref, budget remaining.

Seal v2

Ownership seals on original works (hallmark+work), enabling licensed use and payments.
